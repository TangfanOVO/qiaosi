# 健康 · 参考前端

一页看完今天，点进去看趋势。**只有前端：它不接任何数据源，也不打算替你接。**

手机健康、手表、快捷指令、各家 app 的口径都不一样，接哪家、怎么存是你的事。
这块只认一种数据格式（见下），你把数喂进来，它负责画好。

| 件 | 是什么 |
|---|---|
| [`health.css`](health.css) | 两层页面的样子。只用底座的变量，亮暗、换重点色自动跟上 |
| [`health.js`](health.js) | 渲染器。零依赖、零网络，给一份数据画出两层 |
| [`tokens.css`](tokens.css) | 配色、字、动效的那组变量（亮暗两套）。换成你自己的也行，健康页只读变量 |
| [`demo.html`](demo.html) | 双击就能看。数是 [`demo-data.js`](demo-data.js) 用固定种子现编的 |

## 长什么样

- **主页**：今天四个大数（步数 / 睡眠 / 静息心率 / HRV）· 心情 24 小时 · 最近 14 天三条小走势 ·
  几点睡几点醒 · 此刻（心率 / 血氧 / 呼吸）· 周期
- **趋势**（点四个大数里任意一个进）：心情 / 步数 / HRV / 静息心率四张曲线，能点能滑 ·
  睡眠节律 · 这一刻 · 折叠在最底下的基本信息

## 用它

```html
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="health.css">
<div id="health"></div>
<script src="health.js"></script>
<script>
var page = HealthPage(document.getElementById('health'), {
  series: (days) => myStore.healthSeries(days),   // 返回下面那个格式；可以是 Promise
  now:    ()     => myStore.healthNow(),
  bio:    { height: '163', weight: '52', born: '1999', sleepGoal: '8', stepGoal: '6000' },
  birthday: '04-20',                                // 可选：只给出生年的话，生日前会多算一岁
  onSaveBio: (bio) => myStore.saveBio(bio),         // 可选：返回 false 或抛错＝没存上
});
</script>
```

返回的对象上有 `refresh()`（重新拉一遍、重画主页）、`openTrend()`、`closeTrend()`。
数据口子出错或者没给，页面照画，缺什么就不画哪块；整页一个数都没有时显示空态。

## 数据格式

### `series(days)` —— 画曲线用的

`days` 会是 14（主页）或 7 / 14 / 30 / 90（趋势页的区间条）。

```js
{
  axis: ['2026-08-30', …, '2026-09-12'],     // 长度 = days，最后一个是今天
  series: {                                   // 每个指标一条，跟 axis 按下标对齐
    steps:      [7120, null, 6804, …],        // ★ 那天没数据给 null，别给 0
    sleep_h:    [7.4, …],                     // 睡了几小时
    sleep_bed:  [23.5, …],                    // 几点躺下，钟点小数：23.5＝23:30，1.2＝01:12
    sleep_wake: [7.1, …],                     // 几点起来，同上
    hrv_ms:     [46.2, …],
    resting_hr: [61, …],
    mood:       [0.32, …],                    // 当天的心情，−1 到 +1
  },
  mood: [                                     // 最近 24 小时的心情读数，给主页那张图
    { t: '2026-09-12T07:40', v: 0.42, labels: ['满足'] },   // t 是本地时间；labels 可以是空的
    …
  ],
  cycles: { last_start: '2026-08-20', gaps: [38, 45, 41] }, // 可选：上次开始是哪天、以往间隔几天
}
```

### `now()` —— 此刻那一份

```js
{ steps, sleep_h, resting_hr, hrv_ms, hr_now, spo2, resp_rate, weight_kg }   // 都是数，没有就 null
```

### `bio` / `onSaveBio(bio)`

`{ height, weight, born, sleepGoal, stepGoal }`，折叠在趋势页最底下。收进来的每一样都真的被用上：

| 填了 | 算出来 |
|---|---|
| 身高、体重 | BMI · 步幅（身高 × 0.415）· 今天走了多远 |
| 出生年 | 年龄 · 最大心率（208 − 0.7 × 年龄）· 心率储备 |
| 两个目标 | 离想睡的差多少 · 离想走的走到了几成 |

## 几条画法上的规矩（都是真踩过的）

| 规矩 | 为什么 |
|---|---|
| 缺的那天是 null，不是 0 | 「那天没数据」和「那天走了 0 步」不是一回事，画成 0 会砸出一个假谷 |
| 心情的填充收在零线上 | 收在底边会把 −0.4 画成「矮一点的正柱」 |
| 主页三条小线各自铺满整宽 | 它们没坐标轴，看的是形状；各自缺的天数不一样，共用横坐标会有一节很空 |
| 睡眠画成竖条，轴从数据里取 | 几点睡比睡了多久要紧；作息会转，写死的轴装不下 |
| 周期不假设 28 天，不预测、不下判断 | 很多人的周期本来就不是一个月；「正不正常」是医生的话 |
| 点 / 滑取值只走 pointer 事件 | 浏览器在 touchend 之后补发的 click 会把刚选中的切回去；松手保留落点 |
| 生长动画滚进视野才长，只长一遍 | 滚回来重播，看着像加载圈 |

## 跟应用里那一页的关系

应用里（`core/web/index.html`）那个健康页还是更早的一版，这个仓库里也没有它要的后端。
这块是后来那版设计，单独放在这儿当参考，**没有接进应用**。

## demo 里的数全是编的

`demo-data.js` 用固定种子现生成 90 天的步数、睡眠、心率、心情和周期，不对应任何真人。
想看空态，demo 页上点「空的」。

demo 页上的「玻璃」会套上隔壁的[液态玻璃](../liquid-glass)（要那个文件夹在旁边），开着玻璃时「亮 / 暗」切黑玻璃和白玻璃。health.css 一个字不用改，玻璃那几行都在 demo.html 里，可以照着接。
